# Noxx for Windows

The download for the Noxx app (beta). Noxx is Rocket League replay analysis: https://pireplays.co.uk

**[Download the latest version](https://github.com/Nox-Labs-x/noxx-app-download/releases/latest/download/Noxx-Setup.exe)**

- Windows 10 or 11.
- The beta is invite only: ask from the Analyse page on the site, then log in to the app with your Noxx account.
- Windows may warn the first time you run it, because the installer isn't signed yet. Press "More info", then "Run anyway".

This repository holds the installer only. The app is proprietary software.
